# SEO y GEO — 5 de noviembre de 2026

## Problema confirmado

La comprobación HTTP inicial del dominio `https://traveldays.tur.ar` encontró las cinco páginas públicas con `noindex, nofollow` tanto en HTML como en `X-Robots-Tag`. `robots.txt` respondía `Disallow: /`. El sitemap respondía 200 y listaba las cinco URLs, pero también estaba bajo el header noindex. El contenido nuevo ya era público: la limitación principal era el artefacto de revisión publicado.

## Implementación y arquitectura

- Se conserva el interruptor explícito de producción; los builds locales y previews siguen sin indexación.
- `npm run build:production` genera un build Next indexable y verifica el resultado. Para Cloudflare se usa `npm run cf:deploy:production`, que reconstruye con las variables de producción y comprueba el artefacto antes de subirlo.
- `scripts/verify-production-seo.mjs` verifica HTML de las cinco páginas, canonical, robots, sitemap y ausencia del header global noindex. No basta con cambiar variables después de compilar: estos archivos se prerenderizan.
- La portada incorpora `WebSite` con nombre Travel Days, idioma español de Argentina, dominio oficial y referencia a la entidad `TravelAgency` existente. No se agregan buscadores internos ficticios, ofertas ni valoraciones.
- Googlebot puede utilizar previews de imagen grandes y fragmentos de texto/video sin los límites explícitos de esos campos. Esto no garantiza que los muestre.
- Se reutilizan Next Metadata API, JSON-LD y Playwright existentes, sin dependencias adicionales. Se conservaron contenido, diseño, datos de contacto y URLs.

## Fuentes oficiales y decisiones

- [Google: nombre del sitio](https://developers.google.com/search/docs/appearance/site-names): `WebSite` en la portada comunica la preferencia de nombre.
- [Google: funciones de IA](https://developers.google.com/search/docs/appearance/ai-features): aplican los fundamentos SEO; no requiere archivos especiales para IA. No se añadió `llms.txt` como supuesto requisito.
- [Google: bloquear indexación](https://developers.google.com/search/docs/crawling-indexing/block-indexing): noindex impide la inclusión en resultados; robots y noindex son controles distintos.
- Guías de la versión instalada de Next en `node_modules/next/dist/docs/`: Metadata, JSON-LD, robots y sitemap.

## Conceptos para mantener el sitio

1. **Rastreo e indexación:** poder descargar una página y poder incluirla en resultados son condiciones diferentes.
2. **Configuración de build:** los metadatos estáticos se generan durante la compilación; cambiar el entorno del servidor no corrige un artefacto anterior.
3. **Entidad de marca:** nombre, dominio, ubicación y perfiles coherentes ayudan a distinguir la agencia de otros usos de “Travel Days”; no reemplazan la autoridad ni el contenido útil.
